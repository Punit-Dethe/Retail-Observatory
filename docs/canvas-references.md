# Reference sources

The user authorized reference clones under `references/`. These are standalone checkouts ignored by the parent repository; their own licenses and histories remain intact.

- [sql.garden](https://github.com/immannino/sql.garden): canvas, node, query and assistant interaction reference. Clone at `references/sql-garden`. License GPL-3.0-or-later. No source copied into the React app.
- [Microsoft Data Formulator](https://github.com/microsoft/data-formulator): tool-driven analysis, iterative context and provenance reference. Clone at `references/data-formulator`. License MIT. No source copied into the current application.
- [DashboardGPT](https://www.dashboardgpt.org/): interaction reference for a floating conversation and spatial accumulation of charts and notes. No source repository or assets copied.
- [React Flow / xyflow](https://github.com/xyflow/xyflow): MIT reusable node-canvas library used as a dependency for the implementation.

This first implementation extends the existing React/Python retail project; it is not a fork of DashboardGPT or a port of the Go/Vue reference app. The original dataset remains UCI Online Retail II with CC BY 4.0 attribution.
